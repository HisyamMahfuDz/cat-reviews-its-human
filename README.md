A one-star review from a house cat about its human — one funny line, written by a program. The cat's human films it sleeping, posts it online, gets paid, and still serves dinner late. The cat is the talent; the human is the intern.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
